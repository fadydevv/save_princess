In  this game, you are a ninja trying to save a princess trapped by a giant squid. Through out the way, you can collect coins. Be careful! The squid is not easy to kill and would require a hit and run tactic to beat it. 

Controls: 
- WASD or Arrow keys for movement
- Space or Left click to attack

Features: 
1. Animation for the player in all directions
2. Enemy animation
3. Coin Animation and coin counter
4. Y-sorting for decorations to add depth
5. Octopus Attack and following the player
6. Camera adjustment to prevent the player to see the void
